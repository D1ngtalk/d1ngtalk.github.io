## 7-1 统计大写辅音字母

英文辅音字母是除A、E、I、O、U以外的字母。本题要求编写程序，统计给定字符串中大写辅音字母的个数。

**输入格式**：  
输入在一行中给出一个不超过80个字符、并以回车结束的字符串。

**输出格式**：  
输出在一行中给出字符串中大写辅音字母的个数。

**输入样例**：  
```c
HELLO World!
```
**输出样例**：
```c
4
```
**解析**：  
先看输入格式：
* 输入在一行中给出一个不超过80个字符、并以回车结束的字符串。

这里有两个信息：一是长度不超过 80，据此可以确定数组要开多大；二是字符串里**可能包含空格**（样例里就有 `HELLO World!`），因此不能用 `scanf("%s", str)` 去读 —— 它读到空格就会停下。要让整行连同空格一起读进来，需要用 `getchar()` 一个一个字符地读，一直读到回车符 `'\n'` 为止：
```c
int i = 0;
char str[80] = {};
while((str[i] = getchar()) != '\n'){
    i++;
}
```
每次循环都是先把读到的字符存进 `str[i]`，再让 `i` 加一。所以循环结束时，`i` 正好等于这一行的字符个数，同时也停在回车符所在的位置上。

再看题目要求，来确定我们需要如何处理：
* 英文辅音字母是除A、E、I、O、U以外的字母。本题要求编写程序，统计给定字符串中大写辅音字母的个数。

要计数的字符必须同时满足两个条件：是 `A`~`Z` 之间的**大写字母**，并且**不是** `A`、`E`、`I`、`O`、`U` 这 5 个元音。所以需要一个整型变量 `count` 来累加个数：
```c
int count = 0;
```
然后把判断放进读取字符的循环里，每读到一个字符就判一次：
```c
while((str[i] = getchar()) != '\n'){
    if(str[i] >= 'A' && str[i] <= 'Z'){     #先筛出大写字母
        switch(str[i]){                     #再排除5个元音
            case 'A':
            case 'E':
            case 'I':
            case 'O':
            case 'U':
                break;                      #是元音，不计数
            default:
                count ++;                   #其余大写字母都是辅音
        }
    }
    i++;
}
```
这里用 `switch` 的 `case` 穿透特性：进入 `case` 后会继续执行后续的语句。5 个元音共用同一个 `break`，只要命中其中任意一个就直接跳出，不会走到 `default` 里去让 `count` 加一；只有既是大写字母、又不在这 5 个里，才会走 `default`，让 `count` 加一。

循环结束后，在末尾补一个字符串结束符，把数组“封口”成合法的字符串：
```c
str[i] = '\0';
```
（本题全程是按单个字符处理的，并没有把 `str` 当成字符串整体使用，所以这一句其实不影响结果，主要是保持习惯。）

最后看输出格式：
* 输出在一行内给出字符串中大写辅音字母的个数。

直接输出 `count` 即可：
```c
printf("%d", count);
```

**完整代码**：
```c
#include <stdio.h>
int main(){
    int i = 0, count = 0;
    char str[80] = {};
    while((str[i] = getchar()) != '\n'){
        if(str[i] >= 'A' && str[i] <= 'Z'){
            switch(str[i]){
                case 'A':
                case 'E':
                case 'I':
                case 'O':
                case 'U':
                    break;
                default:
                    count ++;
            }
        }
        i++;
    }
    str[i] = '\0';
    printf("%d", count);
}
```

## 7-5 查找指定字符

本题要求编写程序，从给定字符串中查找某指定的字符。

**输入格式**：  
输入的第一行是一个待查找的字符。第二行是一个以回车结束的非空字符串（不超过80个字符）。

**输出格式**：  
如果找到，在一行内按照格式“index = 下标”输出该字符在字符串中所对应的最大下标（下标从0开始）；否则输出"Not Found"。

**输入样例1**：  
```c
m
programming
```

**输出样例1**：
```c
index = 7
```
**输入样例2**：
```c
a
1234
```

**输出样例2**：
```c
Not Found
```

**解析**：  
先看输入格式：
* 输入的第一行是一个待查找的字符。第二行是一个以回车结束的非空字符串（不超过80个字符）。

第一行只有一个字符，用 `%c` 读入即可：
```c
char c;
scanf("%c", &c);
```
但这里有个坑：`%c` 会**原样**读入一个字符，不会跳过空白字符，而第一行输完之后，缓冲区里还留着一个回车符 `'\n'`。如果紧接着就用 `getchar()` 读第二行，第一个读到的就是这个回车，循环会立刻结束，等于什么都没读到。所以要在格式串后面加一个 `\n`，让 `scanf` 把这个回车（以及后面所有的空白字符）一起跳过：
```c
char c;
scanf("%c\n", &c);
```

第二行是一个可能含空格的字符串，同样用 `getchar()` 逐个字符读入，读到回车为止：
```c
char str[80] = {};
int i = 0;
while((str[i] = getchar()) != '\n'){
    i++;
}
```

再看题目要求，来确定我们需要如何处理：
* 如果找到，在一行内按照格式“index = 下标”输出该字符在字符串中所对应的最大下标（下标从0开始）；否则输出"Not Found"。

“**最大下标**”是关键 —— 说明不能找到第一个就停下，而要把整个字符串走完，让后面出现的下标不断覆盖前面的，最后留下的自然就是最大的那个。所以需要一个整型变量 `index` 记录下标，初始值设为 `-1`，表示“暂时还没找到”：
```c
int index = -1;
```
然后把比较放进读取字符的循环里，边读边判断，找到就把当前位置记下来：
```c
while((str[i] = getchar()) != '\n'){
    if(str[i] == c){        #找到就更新
        index = i;          #后面的匹配会覆盖前面的，最后留下最大下标
    }
    i++;
}
```
这样就不需要等整个字符串读完再遍历一遍，和前面几题“边读边算”的思路是一致的。

最后看输出格式：
* 如果找到，在一行内按照格式“index = 下标”输出；否则输出"Not Found"。

判断的依据就是 `index` 有没有被更新过 —— 仍然是 `-1`，就说明一次都没匹配上：
```c
if(index == -1){
    printf("Not Found");
}else{
    printf("index = %d", index);
}
```

**完整代码**：
```c
#include <stdio.h>
int main(){
    char c;
    char str[80] = {};
    int i = 0, index = -1;
    scanf("%c\n", &c);
    while((str[i] = getchar()) != '\n'){
        if(str[i] == c){
            index = i;
        }
        i++;
    }
    if(index == -1){
        printf("Not Found");
    }else{
        printf("index = %d", index);
    }
}
```
## 7-8 删除重复字符

本题要求编写程序，将给定字符串去掉重复的字符后，按照字符ASCII码顺序从小到大排序后输出。

**输入格式**：  
输入是一个以回车结束的非空字符串（少于80个字符）。

**输出格式**：  
输出去重排序后的结果字符串。

**输入样例**：
```c
ad2f3adjfeainzzzv
```
**输出样例**：
```c
23adefijnvz
```
**解析**：  
先看输入格式：
* 输入是一个以回车结束的非空字符串（少于80个字符）。

还是一个可能含空格的整行字符串，用 `getchar()` 逐个字符读入，存进字符数组 `str`，变量 `i` 同时充当“已存入的字符个数”：
```c
char str[80] = {};
int i = 0;
while((str[i] = getchar()) != '\n'){
    i++;
}
```

再看题目要求，来确定我们需要如何处理：
* 将给定字符串去掉重复的字符后，按照字符ASCII码顺序从小到大排序后输出。

要做两件事：先**去重**，再**排序**。去重可以直接在读入的时候顺手完成，不需要读完再单独处理一遍。思路是：每读到一个字符，就把它和前面已经存下来的字符逐个比较，如果前面已经出现过，说明重复了，就把它丢掉。

这里的“丢掉”不需要真的去挪动数组，只要把 `i` 退回去 —— 下一个读到的字符会写到同一个位置上，把它覆盖掉：
```c
while((str[i] = getchar()) != '\n'){
    i++;                            #刚读到的字符现在位于str[i-1]
    for(int j = 0; j < i - 1;j++){  #与前面已有的字符逐个比较
        if(str[i - 1] == str[j]){   #发现重复
            i--;                    #i退一格，这个位置作废
        }
    }
}
```
注意 `i++` 是在比较之前做的：字符先存进 `str[i]`，`i` 加一之后，刚读到的这个字符就落在 `str[i-1]` 上，而 `str[0] ~ str[i-2]` 是之前保留下来的、互不相同的字符。内层循环要做的，就是把它和这些字符挨个比一遍。如果一次都没重复，`i` 就保留下来，这个字符正式成为结果的一部分；如果重复，`i` 退回去，等待被后面的字符覆盖。

这样循环结束时，`str[0] ~ str[i-1]` 就是去重后的结果，`i` 也正好是去重后的长度。

接着是排序。要按 ASCII 码从小到大排序，元素只有几十个，用最基础的**冒泡排序**就够了：外层控制趟数，内层相邻两个元素比较，前面的比后面的大就交换，一趟走完，最大的那个会“冒”到末尾：
```c
for(int j = 0; j < i - 1; j++){
    for(int k = 0; k < i - 1 - j; k++){
        if(str[k] > str[k + 1]){    #前面的大就交换
            int temp;
            temp = str[k];
            str[k] = str[k + 1];
            str[k + 1] = temp;
        }
    }
}
```
内层循环的条件是 `k < i - 1 - j`：每完成一趟，末尾就多出一个已经排好的元素，所以下一趟可以少比较一次。

比较字符大小，其实比较的就是它们的 ASCII 码 —— 数字 `'0'~'9'` 的码值小于大写字母，大写字母又小于小写字母，所以排完序后数字自然排在前面、字母排在后面，也就是样例里 `23` 在前、`adefijnvz` 在后的样子。

最后看输出格式：
* 输出去重排序后的结果字符串。

按长度 `i` 逐个字符输出即可：
```c
for(int k = 0; k < i;k++){
    printf("%c", str[k]);
}
```

**完整代码**：
```c
#include <stdio.h>
int main(){
    char str[80] = {};
    int i = 0;
    while((str[i] = getchar()) != '\n'){
        i++;
        for(int j = 0; j < i - 1;j++){
            if(str[i - 1] == str[j]){
                i--;
            }
        }
    }
    str[i] = '\0';
    
    for (int j = 0; j < i - 1; j++){
        for (int k = 0; k < i - 1 - j; k++){
            if (str[k] > str[k + 1]) {
                int temp;
                temp = str[k];
                str[k] = str[k + 1];
                str[k + 1] = temp;
            }
        }
    }
        
    for(int k = 0; k < i;k++){
        printf("%c", str[k]);
    } 
}
```
