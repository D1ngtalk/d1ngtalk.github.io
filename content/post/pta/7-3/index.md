## 7-1 统计大写辅音字母

英文辅音字母是除A、E、I、O、U以外的字母。本题要求编写程序，统计给定字符串中大写辅音字母的个数。

**输入格式**：  
输入在一行中给出一个不超过80个字符、并以回车结束的字符串。

**输出格式**：  
输出在一行中给出字符串中大写辅音字母的个数。

**输入样例**：  
```c
HELLO World!
```
**输出样例**：
```c
4
```
**解析**：  
先看输入格式：
* 输入在一行中给出一个不超过80个字符、并以回车结束的字符串。

这里有两个信息：一是长度不超过 80，据此可以确定数组要开多大；二是字符串里**可能包含空格**（样例里就有 `HELLO World!`），因此不能用 `scanf("%s", str)` 去读 —— 它读到空格就会停下。要让整行连同空格一起读进来，需要用 `getchar()` 一个一个字符地读，一直读到回车符 `'\n'` 为止：
```c
int i = 0;
char str[80] = {};
while((str[i] = getchar()) != '\n'){
    i++;
}
```
每次循环都是先把读到的字符存进 `str[i]`，再让 `i` 加一。所以循环结束时，`i` 正好等于这一行的字符个数，同时也停在回车符所在的位置上。

再看题目要求，来确定我们需要如何处理：
* 英文辅音字母是除A、E、I、O、U以外的字母。本题要求编写程序，统计给定字符串中大写辅音字母的个数。

要计数的字符必须同时满足两个条件：是 `A`~`Z` 之间的**大写字母**，并且**不是** `A`、`E`、`I`、`O`、`U` 这 5 个元音。所以需要一个整型变量 `count` 来累加个数：
```c
int count = 0;
```
然后把判断放进读取字符的循环里，每读到一个字符就判一次：
```c
while((str[i] = getchar()) != '\n'){
    if(str[i] >= 'A' && str[i] <= 'Z'){     #先筛出大写字母
        switch(str[i]){                     #再排除5个元音
            case 'A':
            case 'E':
            case 'I':
            case 'O':
            case 'U':
                break;                      #是元音，不计数
            default:
                count ++;                   #其余大写字母都是辅音
        }
    }
    i++;
}
```
这里用 `switch` 的 `case` 穿透特性：进入 `case` 后会继续执行后续的语句。5 个元音共用同一个 `break`，只要命中其中任意一个就直接跳出，不会走到 `default` 里去让 `count` 加一；只有既是大写字母、又不在这 5 个里，才会走 `default`，让 `count` 加一。

循环结束后，在末尾补一个字符串结束符，把数组“封口”成合法的字符串：
```c
str[i] = '\0';
```
（本题全程是按单个字符处理的，并没有把 `str` 当成字符串整体使用，所以这一句其实不影响结果，主要是保持习惯。）

最后看输出格式：
* 输出在一行内给出字符串中大写辅音字母的个数。

直接输出 `count` 即可：
```c
printf("%d", count);
```

**完整代码**：
```c
#include <stdio.h>
int main(){
    int i = 0, count = 0;
    char str[80] = {};
    while((str[i] = getchar()) != '\n'){
        if(str[i] >= 'A' && str[i] <= 'Z'){
            switch(str[i]){
                case 'A':
                case 'E':
                case 'I':
                case 'O':
                case 'U':
                    break;
                default:
                    count ++;
            }
        }
        i++;
    }
    str[i] = '\0';
    printf("%d", count);
}
```

## 7-5 查找指定字符

本题要求编写程序，从给定字符串中查找某指定的字符。

**输入格式**：  
输入的第一行是一个待查找的字符。第二行是一个以回车结束的非空字符串（不超过80个字符）。

**输出格式**：  
如果找到，在一行内按照格式“index = 下标”输出该字符在字符串中所对应的最大下标（下标从0开始）；否则输出"Not Found"。

**输入样例1**：  
```c
m
programming
```

**输出样例1**：
```c
index = 7
```
**输入样例2**：
```c
a
1234
```

**输出样例2**：
```c
Not Found
```

**解析**：  
先看输入格式：
* 输入的第一行是一个待查找的字符。第二行是一个以回车结束的非空字符串（不超过80个字符）。

第一行只有一个字符，用 `%c` 读入即可：
```c
char c;
scanf("%c", &c);
```
但这里有个坑：`%c` 会**原样**读入一个字符，不会跳过空白字符，而第一行输完之后，缓冲区里还留着一个回车符 `'\n'`。如果紧接着就用 `getchar()` 读第二行，第一个读到的就是这个回车，循环会立刻结束，等于什么都没读到。所以要在格式串后面加一个 `\n`，让 `scanf` 把这个回车（以及后面所有的空白字符）一起跳过：
```c
char c;
scanf("%c\n", &c);
```

第二行是一个可能含空格的字符串，同样用 `getchar()` 逐个字符读入，读到回车为止：
```c
char str[80] = {};
int i = 0;
while((str[i] = getchar()) != '\n'){
    i++;
}
```

再看题目要求，来确定我们需要如何处理：
* 如果找到，在一行内按照格式“index = 下标”输出该字符在字符串中所对应的最大下标（下标从0开始）；否则输出"Not Found"。

“**最大下标**”是关键 —— 说明不能找到第一个就停下，而要把整个字符串走完，让后面出现的下标不断覆盖前面的，最后留下的自然就是最大的那个。所以需要一个整型变量 `index` 记录下标，初始值设为 `-1`，表示“暂时还没找到”：
```c
int index = -1;
```
然后把比较放进读取字符的循环里，边读边判断，找到就把当前位置记下来：
```c
while((str[i] = getchar()) != '\n'){
    if(str[i] == c){        #找到就更新
        index = i;          #后面的匹配会覆盖前面的，最后留下最大下标
    }
    i++;
}
```
这样就不需要等整个字符串读完再遍历一遍，和前面几题“边读边算”的思路是一致的。

最后看输出格式：
* 如果找到，在一行内按照格式“index = 下标”输出；否则输出"Not Found"。

判断的依据就是 `index` 有没有被更新过 —— 仍然是 `-1`，就说明一次都没匹配上：
```c
if(index == -1){
    printf("Not Found");
}else{
    printf("index = %d", index);
}
```

**完整代码**：
```c
#include <stdio.h>
int main(){
    char c;
    char str[80] = {};
    int i = 0, index = -1;
    scanf("%c\n", &c);
    while((str[i] = getchar()) != '\n'){
        if(str[i] == c){
            index = i;
        }
        i++;
    }
    if(index == -1){
        printf("Not Found");
    }else{
        printf("index = %d", index);
    }
}
```
## 7-8 删除重复字符

本题要求编写程序，将给定字符串去掉重复的字符后，按照字符ASCII码顺序从小到大排序后输出。

**输入格式**：  
输入是一个以回车结束的非空字符串（少于80个字符）。

**输出格式**：  
输出去重排序后的结果字符串。

**输入样例**：
```c
ad2f3adjfeainzzzv
```
**输出样例**：
```c
23adefijnvz
```
**解析**：  
先看输入格式：
* 输入是一个以回车结束的非空字符串（少于80个字符）。

和上一题一样，字符串里可能有空格，所以还是用 `getchar()` 一个一个字符地读，读到回车符 `'\n'` 为止：
```c
char temp;
while((temp = getchar()) != '\n'){

}
```
每个字符读进来后都暂时放在 `temp` 里，具体拿它做什么，要结合题目要求来定。

再看题目要求，来确定我们需要如何处理：
* 将给定字符串去掉重复的字符后，按照字符ASCII码顺序从小到大排序后输出。

要做两件事：先**去重**，再按 **ASCII 码顺序**排序。

不过再仔细想想：题目只要求“每个出现过的字符输出一次，且按 ASCII 码从小到大”，所以我们并不需要知道每个字符出现了几次、先后出现在哪里，只需要知道**哪些字符出现过** —— 保留住“出现过”这一条信息就够了。

而 ASCII 码一共只有 128 个（0~127），正好可以拿字符的 ASCII 码**当数组下标**，做一个“标记表”：哪个字符出现过，就在对应的格子里做个记号。数组开 128 个元素，下标和字符就一一对应上了：
```c
char str[128] = {};
```
读到一个字符，就用它自己的码值当下标，把自己存进对应的格子：
```c
while((temp = getchar()) != '\n'){
    str[temp] = temp;   #用字符的码值当下标，把自己放进对应的格子
}
```
这一步顺便就把**去重**做完了：同一个字符不管出现多少次，下标都是同一个，反复写也只是反复覆盖同一个格子，最后每个字符只占一个位置。

而且数组初始化为 0 之后，没出现过的格子一直是 0，出现过的格子是非 0，所以“某个字符到底有没有出现过”，看一眼格子里的值就知道了。这里存 `temp` 本身而不是存 1，是为了后面输出时直接把格子里的值打出来，省掉一次转换。

最后看输出格式：
* 输出去重排序后的结果字符串。

因为**下标就是 ASCII 码**，所以只需要从下标 0 扫到 127，遇到非 0 的格子就把里面的字符打出来。扫描的顺序本身就是码值从小到大，输出的结果天然有序，**去重和排序一步到位**：
```c
for(int i = 0; i < 128;i++){
    if(str[i] != 0){        #格子非0，说明这个字符出现过
        printf("%c", str[i]);
    }
}
```
这种“拿值当下标、再按下标顺序扫一遍”的做法，其实就是**桶排序**（计数排序）的思想：把每个元素丢进它对应的桶里，再按桶的顺序依次取出来，结果天然就是有序的。

回到样例 `ad2f3adjfeainzzzv`：读入时 `a` 写了三次、`z` 也写了三次，但每次都落在同一个格子里，最后整张表里只有 11 个非 0 的格子；从 0 扫到 127，先遇到 `2`、`3`，再依次遇到 `a d e f i j n v z`，输出正好是 `23adefijnvz`。

**完整代码**：
```c
#include <stdio.h>
int main(){
    char str[128] = {};
    char temp;
    while((temp = getchar()) != '\n'){
        str[temp] = temp;
    }
    for(int i = 0; i < 128;i++){
        if(str[i] != 0) printf("%c", str[i]);
    } 
}
```
