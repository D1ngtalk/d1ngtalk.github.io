## 7-1 输出数组元素

本题要求编写程序，对顺序读入的n个整数，顺次计算后项减前项之差，并按每行三个元素的格式输出结果。

**输入格式**：  
输入的第一行给出正整数n（1<n≤10）。随后一行给出n个整数，其间以空格分隔。

**输出格式**：  
顺次计算后项减前项之差，并按每行三个元素的格式输出结果。数字间空一格，行末不得有多余空格。

**输入样例**：
```c
10
5 1 7 14 6 36 4 28 50 100
```
**输出样例**：
```c
-4 6 7
-8 30 -32
24 22 50
```
**解析**：  
先看输入格式：
* 输入的第一行给出正整数n（1<n≤10）。随后一行给出n个整数，其间以空格分隔。

也就是需要先读入 n，再用一个数组把这 n 个数存下来。因为 n 最大是 10，数组开 10 个元素就够：
```c
int n;
int num[10] = {};
scanf("%d", &n);
for(int i = 0;i < n;i++){
    scanf("%d", &num[i]);
}
```

再看题目要求，来确定我们需要如何处理：
* 顺次计算后项减前项之差

“后项减前项”就是相邻两个数相减，也就是 `num[i] - num[i-1]`。第一个数前面没有数，所以从第二个数开始算。而“前一项”在上一轮循环里已经读进数组了，因此不必等 n 个数全部读完再遍历一遍，可以边读边算：
```c
for(int i = 0;i < n;i++){
    scanf("%d", &num[i]);
    if(i != 0){                         #第一个数没有前项，跳过
        int temp = num[i] - num[i-1];   #后项减前项
    }
}
```
这里的 `temp` 就是第 i 个数减第 i-1 个数的结果。又因为第一个数不产生差值，所以第 i 个数算出来的差值，正好是第 i 个要输出的数 —— 这一点在后面控制换行时正好能用到。

最后看输出格式：
* 并按每行三个元素的格式输出结果。数字间空一格，行末不得有多余空格。

“每行三个”意味着每输出 3 个数字就要换行；“行末不得有多余空格”意味着最后一个数字后面不能再跟空格。两个要求合起来，输出就分三种情况：
* 这一行已经满 3 个（`i % 3 == 0`）→ 输出数字并换行
* 还没到最后一个（`i != n - 1`）→ 输出数字，后面加一个空格
* 剩下的就是最后一个 → 只输出数字，什么都不加
```c
if(i % 3 == 0){
    printf("%d\n", temp);       #满3个，换行
}else if(i != n - 1){
    printf("%d ", temp);        #不是最后一个，数字后加空格
}else{
    printf("%d", temp);         #最后一个，后面不加空格
}
```
注意判断的顺序：先判 `i % 3 == 0`，再判是不是最后一个。因为“刚好满 3 个”和“是最后一个”可能同时成立（n = 10 时第 9 个差值就是），这时应该按“换行”处理，所以满 3 个的判断要放在前面。

**完整代码**：
```c
#include <stdio.h>
int main(){
    int n;
    int num[10] = {};
    scanf("%d", &n);
    for(int i = 0;i < n;i++){
        scanf("%d", &num[i]);
        if(i != 0){
            int temp = num[i] - num[i-1];
            if(i % 3 == 0){
                printf("%d\n", temp);
            }else if(i != n - 1){
                printf("%d ", temp);
            }else{
                printf("%d", temp);
            }
        }
    }
}
```
## 7-2 打印数字下三角矩阵

n阶数字下三角矩阵是由1开始的自然数依次排列成的一个n行的下三角矩阵，例如，n=5、6时，数字下三角矩阵如输出样例所示。要求输入整数n，构造并输出n阶数字下三角矩阵。

**输入格式**:  
首先输入一个正整数T，表示测试数据的组数，然后是T组测试数据。每组测试输入一个正整数n（n不大于10)。

**输出格式**:  
对于每组测试，输出n阶数字下三角矩阵。每行的每两个数字之间留一个空格。

**输入样例**:
```c
2
5
6
```
**输出样例**:
```c
11
7 12
4 8 13
2 5 9 14
1 3 6 10 15
16
11 17
7 12 18
4 8 13 19
2 5 9 14 20
1 3 6 10 15 21
```
**解析**：  
先看输入格式：
* 首先输入一个正整数T，表示测试数据的组数，然后是T组测试数据。每组测试输入一个正整数n（n不大于10)。

也就是先读入 T，再循环 T 次，每次读入一个 n：
```c
int t;
scanf("%d", &t);
for(int i = 0;i < t;i++){
    int n;
    scanf("%d", &n);
}
```
由于每组测试都是一份独立的矩阵、也都从 1 开始填数，所以矩阵和“下一个要填的数字”都要定义在循环内部，保证每组重新开始：
```c
for(int i = 0;i < t;i++){
    int n, temp = 1;            #temp是下一个要填的数字
    int num[10][10] = {};       #n不超过10，开10×10就够
    scanf("%d", &n);
}
```

再看题目要求，来确定我们需要如何处理：
* 要求输入整数n，构造并输出n阶数字下三角矩阵。

先观察样例里数字的走向：1 单独占一条斜线，2、3 是下一条斜线，4、5、6 又是下一条……也就是说，数字是**一条斜线一条斜线**依次往上填的，第 0 条斜线 1 个元素，第 1 条 2 个，第 2 条 3 个，依此类推。

我们把样例中 n = 5 的情况**顺时针旋转90度**，就能看出以下规律：同一条斜线上的元素**行号 + 列号 相等**。以 n = 5（5×5 的矩阵，一共 15 个数字）为例，下标从 0 开始，填数的循环跑完之后，矩阵里是这样的 —— 行是横坐标 x，列是纵坐标 y，空白表示这个位置不填数：

| x \ y | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 0 | 1 | 2 | 4 | 7 | 11 |
| 1 | 3 | 5 | 8 | 12 |  |
| 2 | 6 | 9 | 13 |  |  |
| 3 | 10 | 14 |  |  |  |
| 4 | 15 |  |  |  |  |

把同一张表里的每一格换成它自己的坐标，得到的就是：

| x \ y | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 0 | (0,0) | (0,1) | (0,2) | (0,3) | (0,4) |
| 1 | (1,0) | (1,1) | (1,2) | (1,3) |  |
| 2 | (2,0) | (2,1) | (2,2) |  |  |
| 3 | (3,0) | (3,1) |  |  |  |
| 4 | (4,0) |  |  |  |  |

两张表对着看：1 在 (0,0)，2 在 (0,1)、3 在 (1,0)，4、5、6 落在下一条斜线上……**同一条斜线上的坐标加起来都相等**（1 是 0+0，2 和 3 都是 0+1，4、5、6 都是 0+2，11~15 的行列和都是 4）。而且斜线的编号每加一，斜线上就多一个元素，所以第 `j` 条斜线正好有 `j + 1` 个元素。因此可以把“行列和”当作斜线的编号 `j`，一条一条地往里填：
```c
for(int j = 0;j < n;j++){           #j是斜线编号，也就是行号+列号
    for(int k = 0;k < j + 1;k++){   #第j条斜线上有j+1个元素
        num[k][j - k] = temp;       #行号是k，列号就是j-k
        temp++;
    }
}
```
让行号 `k` 从 0 走到 `j`，列号自然就是 `j - k`，两者相加正好等于这条斜线的编号 `j`，一条斜线就这样从上到下填满了。

最后看输出格式：
* 对于每组测试，输出n阶数字下三角矩阵。每行的每两个数字之间留一个空格。

看样例的形状：第一行 1 个数，第二行 2 个数……第 n 行 n 个数。再对照上面那张表就清楚了 —— 样例输出的每一行，正好是表里**从右往左的每一列**：第一行只有 y = 4 这一列（也就是 (0,4) 那一格的 11）；第二行是 y = 3 这一列从上往下的 7、12；第三行是 y = 2 这一列的 4、8、13……而每一列有几个元素，正好是 n 减去列号（y = 4 时 1 个，y = 3 时 2 个，y = 0 时 5 个）。所以输出就是**按列号从大到小**，每列从上往下打出来的。

于是用一个变量 `line` 记录当前这一行要输出几个元素，从 1 开始，每换一行就加一：
```c
int line = 1;
for(int j = n - 1;j >= 0;j--){      #列号从最后一列往前推
    for(int k = 0;k < line;k++){

    }
    line++;                         #越往左，这一列的元素越多
    printf("\n");
}
```
每行最后一个数字后面不能多出空格，所以在内层循环里还要判断一下是不是这一行的末尾：
```c
if(k == line - 1){
    printf("%d", num[k][j]);        #每行最后一个，后面不加空格
}else{
    printf("%d ", num[k][j]);
}
```

**完整代码**：
```c
#include <stdio.h>
int main(){
    int t;
    scanf("%d", &t);
    for(int i = 0;i < t;i++){
        int n, temp = 1;
        int num[10][10] = {};
        scanf("%d", &n);
        for(int j = 0;j < n;j++){
            for(int k = 0;k < j + 1;k++){
                num[k][j - k] = temp;
                temp++;
            }
        }
        int line = 1;
        for(int j = n - 1;j >= 0;j--){
            for(int k = 0;k < line;k++){
                if(k == line - 1){
                    printf("%d", num[k][j]);
                }else{
                    printf("%d ", num[k][j]);
                }
            }
            line++;
            printf("\n");
        }
    }
}
```
